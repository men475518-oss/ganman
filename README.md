# GANMAN — ロックマン風 横スクロールアクション

スマホのブラウザ（iOS Safari / Android Chrome）で快適に遊べる、
クラシックなロックマン風の横スクロールアクションプラットフォーマーです。

**HTML5 + 素の JavaScript / Canvas 2D のみ**で作られており、
外部ライブラリも画像・音声ファイルも一切使いません
（ドット絵はコード内で生成、BGM と効果音は Web Audio でその場で合成）。

---

## 遊び方

### そのまま遊ぶ

`index.html` をブラウザで開くだけです。ビルドもサーバーも不要です。

スマホに転送して遊ぶ場合は、1ファイルにまとめた版が便利です:

```
dist/ganman.html          ← これ1つで動きます（file:// でもOK）
dist/ganman-artifact.html ← Artifact 公開用（本文のみ・文書タグなし）
```

**横持ち（landscape）推奨**です。縦向きのときは案内が表示されます。

### 操作（フルタッチ対応）

| 操作 | タッチ | キーボード |
|---|---|---|
| 移動・はしご昇降 | 左下の仮想スティック（触った場所が中心になります） | ← → ↑ ↓ / WASD |
| ジャンプ | 右下 **JUMP** ボタン（長押しで高く跳ぶ） | X / K / Space |
| ショット | 右下 **SHOT** ボタン（**長押しでチャージショット**） | Z / J |
| 武器切り替え | 右上 **WPN** ボタン | C / Q / L / Shift |
| ポーズ（武器選択・E缶） | 右上 **II** ボタン | P / Esc |
| 決定 | 画面中央〜右をタップ | Enter |

- メニューでは**パネルを直接タップ**で選択、**もう一度タップで決定**です。
- 起動時の「TAP TO START」は、iOS で音を鳴らすために必要なタップです。

## ゲーム内容

### ボス6体と弱点の輪

ボスを倒すとその武器が手に入ります。弱点は**輪になっている**ので、
どのボスから挑んでも最後まで攻略できます。

| ボス | 入手武器 | 弱点 | 技（HP半減で強化） |
|---|---|---|---|
| **CUT MAN** | ローリングカッター | スーパーアーム | ブーメランカッター / 突進斬り / 空中複数カッター |
| **ELEC MAN** | サンダービーム | ローリングカッター | 電撃弾連射 / 垂直電撃柱 / 水平電撃ビーム |
| **ICE MAN** | アイススラッシャー | サンダービーム | 3方向氷弾 / 滑る床生成 / 氷の壁で挟み込み |
| **FIRE MAN** | ファイアーストーム | アイススラッシャー | 火炎放射 / 放射状火弾 / 火の玉投下 |
| **BOMB MAN** | ハイパーボム | ファイアーストーム | 遅延爆弾 / 時限地雷 / 爆弾の雨 |
| **GUTS MAN** | スーパーアーム | ハイパーボム | 岩投げ / 着地衝撃波 / 岩連打＋破片 |

```
ガッツ ← ボム ← ファイアー ← アイス ← エレック ← カッター ← ガッツ
```

弱点武器は**ダメージ3倍**です。ステージセレクトでは、
その武器を持っていれば弱点がヒントとして表示されます。

### 敵（14種）

| 敵 | 特徴 |
|---|---|
| **メットール** | 普段はヘルメットで無敵。顔を出した時だけ攻撃でき、3方向弾を撃つ |
| **飛行敵** | 上下に波打ちながら突っ込んでくる |
| **砲台** | 床に固定。撃つ前に光って予告してから狙い撃つ |
| **跳ね敵** | プレイヤーの方へジャンプで詰めてくる |
| **転がる棘** | 床を往復。接触ダメージ大、凍らせられない |
| **盾持ち兵** | **正面からの弾を盾で弾く**。撃つ瞬間だけ盾を下げるのでそこが狙い目 |
| **ぶら下がり** | 天井で待ち構え、真下を通ると落ちてきて追いかけてくる |
| **壁這い** | 床・壁・天井を伝って角を回り込みながらぐるぐる回る |
| **装甲車** | 硬くて遅い。**通常弾は効きが悪く**、3方向の拡散弾を撃つ |
| **分裂体** | 倒すと小さいのが2体に分かれる |
| **飛び出し** | 水中や穴に潜んでいて、近づくと放物線を描いて飛び出す |
| 火炎噴出口 | 破壊不可。予告のあと炎の柱を吹き上げる |
| プレス機 | 破壊不可。周期的に落ちてくる |
| 動く足場 | 大穴を渡るための乗り物 |

### ステージギミック

| ギミック | 挙動 |
|---|---|
| **ベルトコンベア** | 乗ると流される。逆走すると進みが遅くなる |
| **明滅ブロック** | 一定周期で出たり消えたり。消える前に点滅で予告する |
| **崩れる床** | 乗ると崩れ始めるので立ち止まれない。しばらくすると復活する |
| **水** | 重力が弱まりゆっくり沈む。ジャンプは地上の約1.2倍の高さ |
| **氷の床** | 滑ってなかなか止まらない |
| **壊せるブロック** | スーパーアームの岩で破壊できる |
| はしご / トゲ / 飛び乗れる床 | 基本のギミック |

明滅ブロックの橋は `o` と `p` を交互に置いているため、
**どちらの位相でも1つおきに足場があり、常に2タイル跳びで渡り切れます**
（タイミングが悪くて渡れなくなることがない）。

### 操作感

原作（ファミコン版）の数値に寄せてあります。

- 歩行速度 `1.35 px/F` ／ ジャンプ初速 `-4.90` ／ 重力 `0.235` ／ 落下上限 `7.0`
- 加速度なし（押した瞬間に最高速）＝キビキビした操作感
- ボタンを離すと上昇が止まる**可変ジャンプ**
- 空中だけ横速度が `1.60` に上がり、跳ぶと遠くまで届く
  （実測：高さ 48px = 3.0タイル ／ 飛距離 69px = 4.3タイル）
- バスターは画面内3発まで／被弾で無敵時間＋点滅＋ノックバック
- トゲは即死、氷の床は滑る

## 技術メモ

### 描画

- 仮想解像度は**縦 224px 固定・横は端末のアスペクトに合わせて可変**（256〜400px）。
  横持ちスマホで黒帯がほぼ出ず、かつキャラが小さくなりすぎない範囲に収めています。
- 拡大は CSS の `image-rendering: pixelated` に任せるので、
  バッキングストアは常に小さく、GPU が最終拡大を行います（スマホでも軽い）。
- タイルの見た目・ドット絵・フォント・小さな塗り円は**起動時にキャンバスへ焼いて**おき、
  毎フレームは `drawImage` するだけにしています。

### 時間で変化するタイル

明滅ブロックや崩れる床は、同じ文字でも時刻によって固体だったりそうでなかったりします。
そのため当たり判定は文字を見るのではなく `solidAt(tx, ty)` を通し、
そこで時計と崩壊状態を参照して答えるようにしています。

ブロックが体の中に出現してしまった場合の保険として `unstick()` があり、
プレイヤーを上下の近い方へ逃がします。

### ボス戦のカメラ

ボス部屋（幅432px）は画面幅（端末により256〜400px）より広いため、
中央固定にするとプレイヤーが端に行ったとき画面外に消えてしまいます。
そこで3段階でカメラ位置を決めています。

1. プレイヤーとボスの中間（自機寄り 65:35）を見る
2. プレイヤーが画面端に張り付かないよう、必ず余白を確保する
3. アリーナの範囲に収める（壁を少し見せる程度の余裕は持たせる）

縦は固定で、**床が常に画面の64%の高さ**に来るようにしています
（ズーム中も同じ位置に来る）。こうすると戦闘が仮想パッドより上で行われ、
指でキャラが隠れません。それでもボスが画面外に出る配置では、
画面端にボスの色の矢印を出して方向を示します。

`bosscam` シナリオが、4種類の画面サイズ × 自機の位置3箇所について
「自機が画面内か」「仮想パッドと重なっていないか」を毎回検証します。

### ループ

固定タイムステップ 60Hz ＋ アキュムレータ方式。
120Hz 端末でも処理落ち時でもゲーム速度が変わりません。
スローモー演出は「更新を間引く」ことで実現しています（描画は毎フレーム）。

**実測 60 FPS 安定**（ヘッドレス Chromium・パーティクル 300 個の高負荷時も最悪フレーム 16.8ms）。

### サウンド

音源ファイルを使わず Web Audio で合成しています。

- 効果音: 矩形波／三角波／ノイズ＋周波数スイープ
- BGM: **デューティ可変パルス波**による12曲のチップチューン。
  「1小節＝16トークンの文字列」で記述し、先読みスケジューラで予約再生します。
- `AudioContext` が使えない環境では**全て無音のまま正常動作**します。

### 地形生成

安全性が保証されたパターンを左から並べて作ります。
ジャンプ性能から逆算した制約（**段差は最大2タイル・穴は最大3タイル**）を
守っているため、越えられない穴や登れない段差は生まれません。

## 開発

### 1ファイルHTMLを作る

```bash
node tools/build.js            # -> dist/ganman.html（普通の単体HTML）
node tools/build-artifact.js   # -> dist/ganman-artifact.html（Artifact公開用）
```

Artifact 版は publish 時に `<!doctype><head><body>` で包まれるため、
文書タグを含まない「本文だけのHTML」として出力しています。

### 自動テスト

ヘッドレス Chromium で実際にプレイし、例外・進行不能・NaN などを検出します。

```bash
npm install --no-save playwright

node tools/smoke.js basic       # タイトル→セレクト→ステージ→操作
node tools/smoke.js reach       # 全6ステージが踏破可能かを探索で検証（重要）
node tools/smoke.js jump        # ジャンプの高さ・飛距離・滞空時間を実測
node tools/smoke.js bosscam     # ボス戦で自機が常に画面内かつパッドに隠れないか
node tools/smoke.js gimmicks    # 全14種の敵と全ギミックが各ステージに出ているか
node tools/smoke.js gimplay     # コンベア・明滅・崩れる床・水が実際に機能するか
node tools/smoke.js boss        # 扉→登場→戦闘→強化→撃破→武器ゲット
node tools/smoke.js allbosses   # 6体すべての全攻撃を通常/強化の両方で実行
node tools/smoke.js weapons     # 武器7種の発射と弱点倍率
node tools/smoke.js mechanics   # 氷の滑り・凍結・ブロック破壊・一方通行足場
node tools/smoke.js death       # はしご・ポーズ・死亡・復活・ゲームオーバー
node tools/smoke.js robust      # タッチ操作・チャージ・画面サイズ変更
node tools/smoke.js fullrun     # 6ステージ全クリア→エンディング
node tools/smoke.js perf        # FPS計測

# 音が使えない環境をシミュレートする
NOAUDIO=1 node tools/smoke.js noaudio

# 単体HTMLビルドに対して実行する場合
GANMAN_TARGET=dist/ganman.html node tools/smoke.js basic
```

#### 踏破可能性チェックについて

`jump` シナリオではジャンプの到達性能を実測できます
（理論値ではなく、実際に飛ばして高さ・飛距離・滞空時間を測ります）。
物理定数を変えたら、この値と下の踏破可能性チェックの両方を確認してください。

地形は手続き的に生成されるため、`reach` シナリオで
**「立てるタイル」をノードにしたグラフ探索**を行い、
スタートからボス扉まで到達できることを毎回確認しています
（移動能力は実性能より控えめに、上3タイル・横4タイルで見積もり）。

あわせて「ボス扉の手前12タイルが平らな床で連続しているか」も確認します。
パターンの並びが想定より右へはみ出すと通路が敷かれず穴が開くことがあり、
実際にこれで一度詰まる地形が生まれました。

地形パターンを追加したら、必ずこのテストを通してください。
たとえば「壊せるブロックの壁」は当初4タイル（64px）の高さがあり、
ジャンプ到達（48px）を超えていたため、スーパーアーム未入手だと
詰んでしまう状態でした。この種の事故を防ぐための安全網です。

### 拡張のしかた

あとから足しやすい構造にしてあります。

- **武器を足す** … `weapons.js` の `WEAPONS` に定義を1行、`SHOOTERS` に発射処理を1つ
- **敵を足す** … `enemies.js` で `Enemy` を継承して `TYPES` に登録
- **ボスを足す** … `bosses.js` で `extend()` を呼び、`runAct()` に技を書く。
  見た目は共通シャーシ＋`decorate()` で作れます
- **地形パターンを足す** … `stages.js` の `PATTERNS` に関数を1つ、`WEIGHTS` に出現率
- **曲を足す** … `music.js` の `TRACKS` に「1小節16トークン」の文字列を並べる
- **効果音を足す** … `audio.js` の `sfx` に1行

デバッグ表示（FPS）は **F1** キーで切り替えられます。
